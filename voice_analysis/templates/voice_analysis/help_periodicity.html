Periodicity Help

감지된 Peak 시점 목록으로 시계열의 periodicity를 정량화하는 방법을 정리한 문서입니다. 현재 페이지의 "현재 확대 구간 Periodicity" 패널 구현 방식도 함께 설명합니다.

현재 구현 요약

현재 voice_analysis 화면은 peak 검출, 같은 모음 내부 이중 peak 병합, 확대 구간 periodicity 계산, 재전사 제약까지 하나의 흐름으로 연결되어 있습니다.

  1. Envelope 기반 peak를 민감도 슬라이더로 유연하게 검출합니다.
  2. 같은 모음 내부에서 2개로 잡힌 peak는 시간 간격 + valley 깊이 기준으로 1개로 병합합니다.
  3. 확대(zoom) 구간의 active peak만 사용해 IPI 기반 periodicity 지표를 계산합니다.
  4. 현재 확대 구간 peak 수를 재전사 버튼의 제약값으로 전달해 Whisper 전사 토큰 수를 맞춥니다.
구현 의도: 약한 모음 peak는 놓치지 않으면서(민감도 유지), 한 모음 내부의 과검출만 줄여 안정적인 periodicity 지표를 얻는 것입니다.

가장 실용적인 방법: IPI 분석

  1. Peak 시점 배열 준비: \(t_1, t_2, \dots, t_n\)
  2. 간격 계산: \(d_i = t_{i+1} - t_i\)
  3. 대표 주기 추정: \(T \approx \mathrm{median}(d_i)\)
  4. 규칙성 점수 계산:
    • 변동계수: \(CV = \frac{\mathrm{std}(d)}{\mathrm{mean}(d)}\)
    • 강건 대안: \(\mathrm{MAD}/\mathrm{median}(d)\)
해석 예시: \(CV < 0.1\) 매우 주기적, \(0.1 \sim 0.25\) 중간 규칙성, \(> 0.25\) 불규칙

정확도를 높이는 추가 방법

  • Autocorrelation: 첫 번째 큰 봉우리의 지연시간을 주기 \(T\)로 사용
  • FFT/Periodogram: 지배 주파수 \(f_0\)를 찾고 \(T = 1/f_0\)
  • Lomb-Scargle: peak time처럼 불규칙 샘플에서 유용
  • Vector Strength:
    \(\phi_i = 2\pi \frac{t_i \bmod T}{T}\)
    \(R = \left| \frac{1}{n} \sum_{i=1}^{n} e^{j\phi_i} \right|\)
    \(R \to 1\)이면 매우 주기적, \(R \to 0\)이면 비주기적

현재 구현 참고

현재 확대 구간 Periodicity는 zoom 구간 내 peak들만 대상으로 계산합니다.

  • 대표 주기 \(T\): IPI의 median
  • 반복률: \(1/T\) (Hz)
  • IPI CV: \(\mathrm{std}/\mathrm{mean}\)
  • 규칙성 등급: CV 기준으로 "매우 규칙적/중간 규칙성/불규칙"
추천 워크플로우: (1) 줌 구간 기준 IPI + CV 계산, (2) 같은 구간 자기상관 기반 \(T\) 계산, (3) 두 결과가 일치하는지 확인

슬라이더 튜닝 가이드

현재 화면에는 같은 모음 내부 이중 peak를 줄이기 위한 두 파라미터가 있습니다.

  • 병합 시간 창 (ms): 이 시간 안의 인접 peak를 같은 모음 후보로 봅니다.
  • Valley 기준 비율: 두 peak 사이 valley가 이 비율보다 높으면 같은 모음으로 병합합니다.

상황별 권장 시작값

  • 빠른 발화 (모음 간격 짧음): 병합 시간 창 70~110ms, Valley 기준 0.45~0.58
  • 보통 발화: 병합 시간 창 100~140ms, Valley 기준 0.55~0.68
  • 느린 발화 (모음 간격 큼): 병합 시간 창 130~190ms, Valley 기준 0.62~0.78
  • 강한 진동/거친 음질 (한 모음 내 과검출): 병합 시간 창 +20~40ms, Valley 기준 +0.05~0.10
  • 약한 모음 누락 (병합 과도): 병합 시간 창 -15~30ms, Valley 기준 -0.05~0.10
빠르게 맞추는 순서: 1) Peak 검출 민감도로 약한 모음을 먼저 잡고, 2) 병합 시간 창으로 이중 peak 범위를 조정한 뒤, 3) Valley 기준 비율로 같은 모음 병합 강도를 미세 조정하세요.
