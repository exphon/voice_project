1. 페이지 개요

이야기 분석 페이지는 Storytelling 과제에서 수집된 자발적 이야기 발화를 분석하는 도구입니다. Forced Alignment를 통해 각 단어의 시작·종료 시간을 파형 위에 시각화하고 수동으로 경계를 조정할 수 있습니다.

2. Storytelling 과제 소개

Storytelling 과제는 화자에게 그림이나 주제를 제시하고 자유롭게 이야기를 말하게 하는 표준화된 발화 수집 과제입니다. 자발 발화(spontaneous speech)로 수집되므로 읽기 과제보다 자연스러운 발화 패턴을 보여줍니다.

이 과제에서 수집된 발화를 Forced Alignment로 분석하면 발화 유창성, 단어 인출 속도, 발화 타이밍 패턴을 정량적으로 확인할 수 있습니다.

Storytelling 과제 유형(예: storytelling_child, storytelling_senior 등)에 따라 분석 대상이 다를 수 있습니다. 음성 레코드의 과제 유형을 확인하세요.

3. 분석 워크플로

  1. 파일 업로드 또는 연결
    .wav·.mp3 파일을 직접 업로드하거나, 음성 레코드 상세 페이지의 🗣️ 이야기 분석하기 버튼으로 자동 연결합니다.
  2. 파형·스펙트로그램 확인
    분석 실행 후 파형(진폭 envelope 포함)과 스펙트로그램이 표시됩니다.
  3. Forced Alignment 실행 (선택)
    Forced Alignment 실행 버튼을 누르면 각 단어의 시작·종료 시간이 산출되어 파형과 스펙트로그램에 오버레이됩니다.

4. 파형(Waveform) 시각화

오디오 전체 파형을 Canvas에 렌더링합니다. 원본 파형(회색) 위에 진폭 Envelope(하늘색)가 겹쳐 표시됩니다.

줌(Zoom) 기능

이야기 발화는 발화 길이가 길어질 수 있으므로, 줌·스크롤 기능으로 특정 구간을 확대하여 발화 경계를 세밀하게 검토하는 것을 권장합니다.

Forced Alignment를 실행하면 각 단어 구간이 반투명 색상 블록으로 표시되고 단어 시작·종료 경계선이 점선으로 그려집니다.

단어 경계선 수동 조정

파형 캔버스에서 단어 경계선(◇ 핸들)을 드래그하거나, 하단 테이블의 시작·종료 셀을 직접 수정할 수 있습니다.

자발적 발화에서는 반복, 수정, 망설임 등이 포함될 수 있어 자동 정렬 결과가 부정확할 수 있습니다. 반드시 파형과 대조하세요.

6. 발화 타이밍 · 정확도 지표

Forced Alignment를 실행하면 정렬된 단어 경계를 바탕으로 첫 단어 시작부터 마지막 단어 끝까지의 발화 타이밍 지표와 전사 정확도가 자동으로 계산되어 정렬 결과 패널에 표시됩니다. 테이블을 편집하거나 경계선을 드래그하면 타이밍 지표가 실시간으로 갱신됩니다.

지표계산 방식단위
발화 소요 시간
(Duration)		 마지막 단어 종료 시간 − 첫 단어 시작 시간 초 (s)
발화 속도
(Speaking rate)		 전체 음절 수 ÷ 전체 소요 시간 (휴지 포함)
한글 음절 블록(가–힣) 글자 수를 음절로 셉니다.		 음절/초
조음 속도
(Articulation rate)		 전체 음절 수 ÷ 순수 발화 시간 (= 소요 시간 − 휴지 총합)
휴지를 제외한 실제 조음 구간만으로 계산하므로 항상 발화 속도 이상입니다.		 음절/초
휴지 비율
(Pause ratio)		 단어 사이 무음(silence) 구간 총합 ÷ 소요 시간 × 100 %

전사 정확도(Accuracy)

Reference 발화(정답 이야기)와 자동 전사 결과를 편집 거리(Levenshtein distance) 기반으로 비교합니다. Reference 입력란에 목표 이야기 텍스트를 입력하면 정확도가 즉시 계산됩니다.

지표계산 방식단위
단어 정확도
(WER 기반)		 (1 − 단어 편집거리 ÷ reference 단어 수) × 100 %
음절 정확도
(CER 기반)		 (1 − 한글 음절 편집거리 ÷ reference 음절 수) × 100 %
타이밍 지표는 단어 경계에 의존하므로, 경계가 부정확하면 먼저 파형·테이블에서 수동 조정한 뒤 값을 확인하세요. 정확도는 전사 텍스트에만 의존하며 Reference 수정 시 재계산됩니다.

7. 사용 팁

  • 자발 발화 특성 고려 — 이야기 발화는 자발적이므로 단어 경계 자동 탐지 정확도가 낭독 과제보다 낮을 수 있습니다. Score가 낮은 단어는 수동으로 검토하세요.
  • 망설임·휴지 확인 — 발화 속도가 느려지거나 묵음 구간이 길어지는 부분은 단어 인출 어려움의 신호일 수 있습니다.
  • 긴 발화에서의 줌 활용 — 이야기 발화는 길어질 수 있으므로 줌 기능을 적극 활용하세요.
  • 음성 레코드 연결 — 레코드 상세 페이지에서 접근하면 화자 정보가 자동으로 표시됩니다.
