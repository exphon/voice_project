1. 페이지 개요

숫자 세기 분석 페이지는 화자가 1, 2, 3, 4, 5 …처럼 순서대로 숫자를 세어 발화한 음성 파일을 분석하는 도구입니다. Forced Alignment를 통해 각 숫자 단어의 시작·종료 시간을 파형 위에 시각화하고 수동으로 경계를 조정할 수 있습니다.

파킨슨병·말더듬·조음 장애 등의 임상 연구에서 발화 타이밍과 단어 경계를 정량적으로 검토하는 데 활용합니다.

2. 분석 워크플로

  1. 파일 업로드 또는 연결
    .wav·.mp3 등 오디오 파일을 직접 업로드하거나, 음성 레코드 상세 페이지의 🔢 숫자 세기 분석 버튼으로 자동 연결합니다.
  2. 파형·스펙트로그램 확인
    분석 실행 후 파형(진폭 envelope 포함)과 스펙트로그램이 표시됩니다. 화자 정보가 있을 경우 자동으로 매칭되어 표시됩니다.
  3. Forced Alignment 실행 (선택)
    Forced Alignment 실행 버튼을 누르면 Whisper가 각 숫자 단어의 시작·종료 시간을 산출하여 파형과 스펙트로그램에 오버레이합니다. 단어 경계선을 드래그하거나 테이블을 직접 편집해 수동 조정할 수 있습니다.

3. 파형(Waveform) 시각화

오디오 전체 파형을 Canvas에 렌더링합니다. 원본 파형(회색) 위에 진폭 Envelope(하늘색)가 겹쳐 표시됩니다.

진폭 Envelope

RMS(Root Mean Square) 에너지를 Short-Time 분석 창 단위로 계산한 값으로, 각 발화의 에너지 변화를 직관적으로 파악하는 데 유용합니다.

줌(Zoom) 기능

파일 길이가 10초를 초과하면 Zoom In / Zoom Out 버튼과 스크롤바가 활성화됩니다. 세밀한 구간을 확대하여 발화 경계를 정확하게 검토할 수 있습니다.

Forced Alignment를 실행하면 각 단어 구간이 반투명 색상 블록(…)으로 표시되고, 단어 시작·종료 경계선이 점선으로 그려집니다.

4. 스펙트로그램 시각화

파형 아래에 0–8 kHz 범위의 STFT 스펙트로그램이 viridis 컬러맵으로 표시됩니다. 파형과 시간 축이 동기화되어 있어 줌·스크롤 시 함께 이동합니다.

파라미터값
FFT 크기1024 포인트
표시 주파수 범위0 – 8,000 Hz
컬러맵viridis (어두움 = 낮은 에너지, 밝음 = 높은 에너지)

Forced Alignment 결과가 스펙트로그램에도 동일하게 오버레이되어, 각 단어의 주파수 특성을 시각적으로 비교할 수 있습니다.

5. Forced Alignment

동작 방식

Forced Alignment 실행 버튼을 누르면 서버에서 오디오를 Whisper로 전사하고, 각 단어의 시작·종료 시간(초)을 추출합니다.

백엔드조건특징
WhisperX whisperx 패키지 설치 시 우선 사용 CTC 기반 강제 정렬 — 더 정밀한 단어 경계
openai-whisper
(fallback)		 WhisperX 미설치 시 자동 전환 Cross-attention DTW 기반 word_timestamps — 실용적 정밀도

분석이 완료되면 파형과 스펙트로그램에 단어 구간이 오버레이되고, 하단 테이블에 각 단어의 시작 시간·종료 시간·신뢰도가 표시됩니다. 상태 메시지에서 어떤 백엔드가 사용됐는지 확인할 수 있습니다. 아울러 정렬 결과를 바탕으로 소요 시간·발화 속도·휴지 비율 등 발화 타이밍 지표가 함께 계산되어 표시됩니다.

단어 경계선 수동 조정

파형 캔버스에서 단어 경계선(◇ 다이아몬드 핸들)을 마우스·터치 드래그로 이동하면 해당 단어의 시작 또는 종료 시간이 실시간으로 수정되고 테이블에 반영됩니다.

테이블 직접 편집

테이블의 시작(s)·종료(s) 셀을 클릭하면 직접 수치를 입력할 수 있습니다(점선 테두리로 표시). 입력 후 포커스를 잃으면(Tab / 다른 곳 클릭) 파형에 즉시 반영됩니다.

Forced Alignment는 숫자 발화 음성에 최적화되어 있습니다. 배경 소음이 심하거나 발화가 불명확할 경우 일부 단어가 누락되거나 경계가 부정확할 수 있으므로, 파형을 보며 수동 조정을 권장합니다.
수동으로 조정한 단어 경계 정보는 현재 브라우저 세션에만 유지되며, 페이지를 새로고침하면 초기화됩니다.

6. 발화 타이밍 지표

Forced Alignment를 실행하면 정렬된 단어 경계를 바탕으로 「하나」 시작부터 「열」 끝까지의 발화 타이밍 지표가 자동으로 계산되어 정렬 결과 패널에 표시됩니다. 테이블을 편집하거나 경계선을 드래그하면 값이 실시간으로 갱신됩니다.

지표계산 방식단위
숫자 세기 소요 시간
(Duration)		 마지막 단어의 종료 시간 − 첫 단어의 시작 시간
end마지막 − start첫		 초 (s)
발화 속도
(Speaking rate)		 전체 음절 수 ÷ 전체 소요 시간 (휴지 포함)
음절 수 ÷ duration
한글 음절 블록(가–힣) 글자 수를 음절로 셉니다. 예: 하나=2, 둘=1, 셋=1 … 열=1		 음절/초
조음 속도
(Articulation rate)		 전체 음절 수 ÷ 순수 발화 시간 (= 소요 시간 − 휴지 총합)
음절 수 ÷ (duration − Σ pause)
휴지를 제외한 실제 조음 구간만으로 계산하므로 항상 발화 속도 이상입니다.		 음절/초
휴지 비율
(Pause ratio)		 단어 사이 무음(silence) 구간 총합 ÷ 소요 시간 × 100
(Σ pause ÷ duration) × 100
인접한 두 단어의 이전 단어 종료 ~ 다음 단어 시작 간격을 모두 합산합니다. 겹치는 구간은 0으로 처리합니다.		 %
세 지표 모두 Forced Alignment의 단어 경계에 의존하므로, 경계가 부정확하면 먼저 파형·테이블에서 수동 조정한 뒤 값을 확인하는 것이 좋습니다.
음절 수는 한글 음절 글자 수로 계산하므로, 전사 결과에 숫자(아라비아 숫자)나 기호가 포함되면 음절로 집계되지 않습니다. 발화 속도가 비정상적으로 낮으면 전사 텍스트를 확인하세요.

전사 정확도(Accuracy)

Reference 발화(정답)와 자동 전사 결과를 편집 거리(Levenshtein distance) 기반으로 비교하여 정확도를 계산합니다. Reference 입력란의 기본값은 하나 둘 셋 넷 다섯 여섯 일곱 여덟 아홉 열이며, 직접 수정하면 정확도가 즉시 재계산됩니다.

지표계산 방식단위
단어 정확도
(WER 기반)		 단어(공백 단위) 편집 거리로 WER을 구한 뒤 정확도로 변환
accuracy = (1 − 편집거리 ÷ reference 단어 수) × 100		 %
음절 정확도
(CER 기반)		 한글 음절(가–힣) 단위 편집 거리로 CER을 구한 뒤 정확도로 변환
accuracy = (1 − 편집거리 ÷ reference 음절 수) × 100		 %
WER은 숫자 단어를 통째로 맞췄는지, CER은 음절 단위까지 세밀하게 일치하는지를 봅니다. 예를 들어 「하나」를 「하」로만 전사하면 WER에서는 1개 오류지만 CER에서는 1음절 오류로 더 부분 점수가 반영됩니다. 편집 거리가 reference 길이보다 클 경우 정확도는 0%로 표시됩니다.

7. 사용 팁

  • Forced Alignment 신뢰도 확인 — 테이블의 Score 열은 각 단어의 인식 신뢰도(0–1)입니다. 0.5 미만이면 해당 단어 경계를 수동으로 검토하세요.
  • 스펙트로그램과 비교 — Forced Alignment 결과와 스펙트로그램의 에너지 집중 구간을 겹쳐보면 단어 경계 정확도를 시각적으로 검증할 수 있습니다.
  • 음성 레코드 연결 후 분석 — 음성 레코드 상세 페이지에서 🔢 숫자 세기 분석 버튼으로 접근하면 화자 정보가 자동으로 표시됩니다.
  • 느린 발화(고령자·환자군) — 발화 간격이 넓어 단어 경계가 명확하므로 Forced Alignment 정확도가 높습니다.
