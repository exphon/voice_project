1. 페이지 개요

지속 모음 분석 페이지는 화자가 발화한 /아/ 발음(sustained vowel)의 음성 파일을 업로드하거나, 음성 레코드 상세 페이지에서 직접 연결하여 다양한 음질 지표를 분석하는 도구입니다.

파킨슨병·성대 질환·발달장애 등 음성 관련 임상 연구 및 데이터 수집 환경에서, 파형 전체 확인 → 모음 구간 수동 선택 → 음질 지표 산출의 흐름으로 사용합니다.

2. 분석 워크플로

  1. 파일 업로드 또는 연결
    .wav·.mp3 등 오디오 파일을 직접 업로드하거나, 음성 레코드 상세 페이지의 🎤 아 발화 분석 버튼으로 자동 연결합니다. 파일명이 DB에 등록된 음성 레코드와 일치하면 화자 정보가 자동으로 표시됩니다.
  2. 파형·스펙트로그램 확인
    분석 실행 후 전체 파형과 스펙트로그램이 표시됩니다. 초록 점선은 자동 감지된 모음 시작, 빨간 점선은 모음 종료를 나타냅니다.
  3. 분석 구간 선택
    파형 위에서 마우스 드래그로 분석할 모음 구간을 지정합니다. 선택된 구간은 반투명 파란 영역으로 강조됩니다. 선택 구간 재생 버튼으로 해당 구간만 들어볼 수 있습니다.
  4. 선택 구간 분석 실행
    분석 시작 버튼을 누르면 서버에서 선택된 구간에 대해 포먼트·지터·쉬머·HNR·CPP·켑스트럼 지표를 산출하여 결과를 표시합니다.
  5. 마커 조정 및 저장(선택)
    모음 시작·종료 마커를 드래그로 수동 조정한 뒤 마커 구간으로 선택 적용을 눌러 정밀 분석에 활용하고, 마커 저장 기능으로 DB에 영구 보존합니다.

3. 파형(Waveform) 시각화

오디오 전체 파형을 Canvas에 렌더링합니다. 파일이 길어도 다운샘플링하여 최대 2,000포인트로 표시하므로 전체 구조를 빠르게 파악할 수 있습니다.

줌(Zoom) 기능

파일 길이가 10초를 초과하면 Zoom In / Zoom Out 버튼과 스크롤바가 활성화됩니다. 화면 너비에 맞게 표시 구간을 확대·이동할 수 있습니다.

구간 선택

파형 캔버스에서 마우스를 클릭·드래그하여 구간을 선택합니다. 선택 구간의 시작·끝 시간(초)은 하단의 선택 정보 레이블에 표시됩니다. 선택 해제 버튼으로 선택을 초기화할 수 있습니다.

4. 스펙트로그램 시각화

파형 아래에 0–8 kHz 범위의 STFT 스펙트로그램이 viridis 컬러맵으로 표시됩니다. X축은 시간(초), Y축은 주파수(Hz)이며, 밝을수록 에너지가 높음을 의미합니다.

파라미터값
FFT 크기1024 포인트
Hop 길이샘플레이트 × 0.8 % (약 8ms)
표시 주파수 범위0 – 8,000 Hz
표시 해상도최대 250 × 100 (시간 × 주파수) 다운샘플링

모음 마커(시작 / 종료)가 스펙트로그램에도 동기화되어 표시됩니다.

스펙트로그램의 에너지 값은 amplitude_to_db로 변환 후 0–1로 정규화됩니다. 절대 dB 값이 아닌 상대적 에너지 분포를 나타냅니다.

5. 모음 마커 (Vowel Onset / Offset)

자동 감지

파일 로드 시 RMS 에너지 기반 알고리즘으로 모음 시작·종료 위치를 자동 추정합니다.

파라미터값
분석 창 길이25 ms
Hop 길이10 ms
에너지 임계값최대 RMS의 8 %

수동 조정 — 드래그

마커 선 위에 마우스를 올리면 커서가 바뀝니다. 클릭·드래그하여 모음 시작과 모음 종료 위치를 자유롭게 이동할 수 있습니다 (± 8px 범위 감지).

마커 구간으로 선택 적용

마커 구간으로 선택 적용 버튼을 누르면 현재 마커 위치가 분석 구간 선택(파란 영역)에 자동 반영되어, 바로 분석 시작을 실행할 수 있습니다.

마커 위치는 분석 재실행 후에도 유지됩니다. 마커를 DB에 저장하면 브라우저 캐시를 삭제해도 복원됩니다.

6. 선택 구간 분석 지표

Praat(parselmouth 래퍼)를 이용하여 선택 구간 중앙 시점 또는 구간 전체에 대해 지표를 산출합니다. 분석 구간은 최소 50 ms 이상이어야 합니다.

7. 켑스트럼(Cepstrum) 분석

선택 구간 전체의 켑스트럼 프로파일을 차트로 시각화합니다. X축은 퀘프렌시(quefrency, ms), Y축은 켑스트럼 진폭(dB)이며, 회귀선(빨간 선)에서 가장 높이 솟은 피크가 CPP 피크(초록 원)입니다.

산출 과정

  1. 선택 구간 샘플에 Hanning 창 적용
  2. FFT → 로그 스펙트럼 → 역 FFT(IFFT)로 켑스트럼 산출
  3. 유효 퀘프렌시 범위(1–20 ms, 50–1000 Hz에 해당) 추출
  4. 선형 회귀선과의 차이로 CPP prominence (dB) 계산
이 CPP는 Praat의 CPPS 값(segment_result.cpp)과 다른, librosa 기반의 자체 추정값(cepstrum_profile.cpp_prominence_db)입니다. 절대값 비교보다는 동일 화자·동일 조건 내에서의 상대적 변화 추적에 활용하십시오.

8. 마커 저장 및 초기화

마커 구간으로 선택 적용 (저장)

파형 하단의 마커 구간으로 선택 적용 버튼을 누르면 현재 마커 위치가 DB에 자동 저장됩니다. 저장된 마커는 다음에 같은 음성 레코드를 분석할 때 서버에서 자동으로 불러와 적용됩니다.

저장 데이터:

  • onset — 모음 시작 시각 (초, 소수점 4자리)
  • offset — 모음 종료 시각 (초, 소수점 4자리)
  • duration_ms — 모음 구간 길이 (ms, 소수점 1자리)

자동 위치로 초기화

자동 위치로 초기화 버튼을 누르면 DB에 저장된 마커가 삭제되고, 다음 분석부터는 RMS 에너지 자동 감지 위치가 다시 사용됩니다.

음성 레코드 ID(audio_record_id)가 매칭된 경우에만 DB 저장이 활성화됩니다. 파일명으로 매칭되지 않는 경우 브라우저 localStorage에 임시 저장됩니다.

9. 사용 팁

  • /아/ 발화 구간 선택 가이드: 발화 시작 직후 안정화된 구간(onset 마커 이후 약 0.2–0.5s)부터 종료 직전(offset 마커 이전 약 0.2s) 사이의 안정 구간을 선택하면 지터·쉬머 신뢰도가 높아집니다.
  • 분석 구간 최소 길이: 피크 검출에 필요한 주기 수 확보를 위해 최소 200–300 ms 이상 선택을 권장합니다 (시스템 최솟값 50 ms).
  • 배경 소음: 녹음 시작·종료 부분의 잡음(방 소음, 키보드 소리)이 포함되면 HNR·CPP가 낮게 산출됩니다. 모음이 안정적으로 발화된 구간만 선택하세요.
  • 반복 분석: 동일 파일에 대해 구간만 바꿔 여러 번 분석 시작을 실행할 수 있습니다. 파일은 다시 업로드할 필요 없이 파형 뷰를 유지한 채 구간만 재선택하면 됩니다.
  • 음성 레코드 연결: 음성 레코드 상세 페이지에서 🎤 아 발화 분석 버튼으로 진입하면 화자 정보 자동 매칭 및 DB 마커 저장이 모두 활성화됩니다.
